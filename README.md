# Sistem Informasi Akademik

Pratinjau responsif antarmuka SIA untuk desktop dan ponsel. Menu Beranda, Akademik, Kegiatan, Profil, serta halaman layanan akademik dapat dibuka tanpa instalasi atau proses build.

## Menjalankan secara lokal

Buka `index.html` di browser. Navigasi menggunakan hash URL, sehingga halaman dapat dibuka langsung dengan alamat seperti `index.html#/nilai` atau `index.html#/jadwal-mahasiswa`.

## Publikasi

Repository ini dikonfigurasi untuk GitHub Pages melalui GitHub Actions. Aktifkan **Settings → Pages → Build and deployment → Source: GitHub Actions**, lalu push ke branch `main`. Rincian publikasi terdapat di [DEPLOYMENT.md](./DEPLOYMENT.md).

URL Pages default: <https://briorisaapriliakalista.github.io/desain-sia/>

## Batasan pratinjau

Nilai, jadwal, tagihan, kegiatan, dan identitas di dalam halaman adalah data contoh. Login, backend kampus, transaksi, dan penyimpanan permanen belum terhubung.
